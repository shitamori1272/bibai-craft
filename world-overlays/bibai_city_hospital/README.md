# 市立美唄病院

美唄市西2条北1丁目に2024年に開院した病棟を、昭和通沿いの旧職員駐車場に配置します。ゲーム内で次を実行すると東側の車寄せを見渡せます。

```mcfunction
/tp @s 1180 -55 1312 125 -12
```

南側に張り出す外来の連続窓、病棟の赤茶色の外壁と縦長窓、東玄関の庇と病院名、低い事務棟、屋上の塔屋と設備を再現しました。玄関から受付・待合を通り、階段で上階を見学できます。寸法・部屋数・内装はゲーム用の近似です。

試遊ワールドで病院周辺のチャンクが読み込まれると、同梱のストラクチャーを一度だけ配置します。配置済みの区画は再読み込み時にも保持します。
