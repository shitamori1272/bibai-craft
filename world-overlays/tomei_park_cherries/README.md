# 東明公園の桜並木

`./start.command preview` で試遊を開始し、コマンド権限のあるプレイヤーがゲーム内チャットで次のコマンドを実行すると、東明公園の道沿いに並ぶ5本の桜を南東側から見渡せます。

```mcfunction
/tp @s 4333 -6 451 130 12
```

サーバーを起動したターミナルから移動させるときは、`list` で接続中のプレイヤー名を確認し、以下の `<プレイヤー名>` を置き換えて実行します。

```text
tp <プレイヤー名> 4333 -6 451 130 12
```

公園周辺の読み込み後は5秒ごとに植栽を試み、草地に桜が生成されます。植えた場所を1本ずつ記録するため、同じ試遊中に木を伐っても再生成されません。
