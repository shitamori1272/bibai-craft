# 石炭クリッカー 企画書

美唄ハッカソン（テーマ「美唄を倍にする」）向けの Minecraft プラグイン。
かつて炭鉱で栄えた美唄の歴史を、放置ゲームを通して知ってもらう。

## 1. コンセプト

**自分の坑道を掘り進め、どんどん深い層へ降りていく放置ゲーム。**

- ゲームの仕組みはクッキークリッカー型：切羽を叩くと石炭が出る（クリック）、道具を買うと毎秒石炭が増える（建物）、改良で効果が何倍にもなる（アップグレード）
- 掘った石炭の累計に応じて坑道が奥へ伸び、1 本掘り切ると立坑のケージで一段深い階層へ降りる。深い層ほど石炭が多く採れる
- 道具と改良の解説を通して、炭鉱の歴史や技術の進歩を知ってもらう

## 2. 動作環境

| 項目 | 内容 |
|---|---|
| サーバー | Paper 26.3（※現在のリポジトリはバニラの公式サーバーなので、Paper への切り替えが必要） |
| Java | 25 |
| 言語 | Java |
| ビルド | Gradle。開発用サーバーの起動には `run-paper` を使う |
| プラグイン名 | `CoalClicker`（仮） |

## 3. 遊びの流れ

1. `/coal mine` で、自分の坑道の先端（切羽）へ入坑する
2. 切羽を叩くたびに石炭がもらえる（叩くとヒビが入る演出つき）
3. `/coal shop` で道具を買うと、毎秒自動で石炭が増えていく。改良を買うと効果が何倍にもなる
4. 累計の採掘量が増えると坑道が奥へ伸びる。1 本掘り切ると数値上は自動で次の階層へ進み、坑内にいる場合はケージで降りるよう誘導する
5. ケージで新しい深さに到達すると、**到達ボーナス**がもらえる
6. 坑外にいる間やログアウト中も、毎秒の石炭は増え続ける（ログアウト中は上限 8 時間）

## 4. 数値の仕組み

単位は「個」。ゲームの仕組みはクッキークリッカーに合わせ、数値の比率もそれを参考にする。以下の数値はすべて初期値で、あとで調整する。

### 4-1. 毎秒の石炭

中心となる数値。画面にいちばん大きく出す。

```
毎秒の石炭 ＝ Σ（道具の基本値 × 所持数 × その道具の改良倍率）× 全体の倍率 × 深さ倍率
```

| 数値 | 計算式 | 意味 |
|---|---|---|
| 道具の改良倍率 | 2 ^（その道具の改良を買った数） | 道具ごとの改良 1 つで、その道具の効果が 2 倍 |
| 全体の倍率 | 全体の改良の積 | すべての石炭に掛かる |
| 深さ倍率 | 1.1 ^ 階層番号（0 始まり） | 深い層ほど石炭が多い |

### 4-2. 手掘り（クリック）

- 自分の坑道の切羽を **1 回叩くごとに** 石炭がもらえる
- 1 回あたりの石炭 ＝ 10 × 手掘りの倍率 ＋ 毎秒の石炭 × 手掘りの上乗せ率
  - 手掘りの倍率：ツルハシの改良 1 つで 2 倍
  - 手掘りの上乗せ率：熟練の改良 1 つで +1%（後半でも手掘りに意味が残る）
- 叩くとヒビが 1 段階進み、10 回で一周する（見た目の演出。坑道の進み方には関係しない）
- 叩いたときに効果音と `+◯個` を表示する
- 連打の上限は 1 tick に 1 回（毎秒 20 回）

### 4-3. 坑道の進み方（累計採掘量）

坑道は、**累計採掘量**（手掘り・毎秒の分・到達ボーナスの合計。管理者の付与は含まない）で進む。

| 数値 | 計算式 |
|---|---|
| 第 n 坑道（階層番号 n−1）を掘り切るのに必要な量 | 6,400 × 2 ^（n−1） |
| 第 n 坑道を掘り切るまでの累計 | 6,400 ×（2 ^ n − 1） |
| 今の階層の進み具合 | （累計 − 前の階層までの累計）÷ この階層に必要な量 |
| 坑道の長さ L | 64 + 16 × 階層番号（m） |
| 表示する距離 | 進み具合 × L |

- 階層は累計採掘量から一意に決まる（数値上の階層）。見た目の階層はケージに乗ったときに追いつく（5-5）
- クッキークリッカー型の経済では後半ほど伸びが緩やかになるため、深い階層ほど 1 階層にかかる時間が長くなる
- 第 1 坑道は 64m・6,400 個なので、最初は手掘り 10 回（100 個）でちょうど 1m 進む
- 以下は必要量が 1,000 個だったときのシミュレーション（1 秒に 4 回・最初の 10 分だけ叩き、あとは効率の良い順に買う）。6,400 個に変えたので、実際はこれより少し遅い

| 経過時間 | 到達 | 毎秒の石炭 |
|---|---|---|
| 10 分 | 第 10 坑道 | 約 7,000 個 |
| 1 時間 | 第 28 坑道 | 約 2.5 億個 |
| 8 時間 | 第 38 坑道 | 約 93 億個 |
| 1 日 | 第 41 坑道 | 約 305 億個 |

### 4-4. 到達ボーナス

- **はじめて到達した階層**に、ケージか入坑で実際に着いたときにもらえる
- 1 階層あたりのボーナス ＝ その階層での毎秒の石炭 × 60 秒分（最低保証は手掘り 1 回分）
- 降りなかった階層がある場合は、その分もまとめてもらえる（深さ倍率は等比数列なので、和の公式で一度に計算する）
- 到達ボーナスは累計採掘量に含めるが、それで階層が進んでも、その階層のボーナスは次に着いたときに渡す

### 4-5. どんなに大きな数でも扱えるようにする

Java の `double` は約 10^308 が上限で、深い階層では石炭の数がこれを超えてしまう。そこで、数値は次のように持つ。

| 値 | 持ち方 | 扱える範囲 |
|---|---|---|
| 石炭・毎秒の石炭・価格・倍率など | 自作の `BigNum`（仮数 `double` 1〜10 未満 ＋ 指数 `long`） | 10^(9×10^18) まで。事実上無限 |
| 階層番号 | `long` | 約 900 京階層まで |
| 今の階層の進み具合 | 累計採掘量から計算する**割合**（0〜1） | 保存しない。m 表示は 割合 × L で出す |

- 深さ倍率 1.1^n は、指数 ＝ n × log10(1.1) として直接求める（掛け算を n 回しない）
- 表示は日本の単位で区切る：万・億・兆・京・垓・秭・穣・溝・澗・正・載・極・恒河沙・阿僧祇・那由他・不可思議・無量大数
- 無量大数（10^68）を超えたら `1.23×10^1234個` のように表示する
- 保存は文字列にする（例：`"1.234e5678"`）

## 5. 坑道システム

### 5-1. 専用ワールド `bibai_mine`

- プラグインが起動時に自動で作る
- 地形は全部岩。空も洞窟もない
- 坑道の高さに地層をつくる

```
Y43-44  砂岩        ← 天井
Y41-42  炭層（石炭鉱石）
Y40     石          ← 床
それ以外 石
```

### 5-2. 区画（1 人 1 本）

- はじめて入坑した順に**区画番号**を割り当てる（0, 1, 2, …）
- 区画 n の坑道は、**Z = n × 16** の位置を **X = 0 から +X 方向**へ伸びる
- 坑道の断面は 幅 3 × 高さ 3（Y41〜43）
- X = -8〜0 は坑底（ケージと人車の乗り場）
- 区画が保持するのは**今の階層の坑道 1 本だけ**
- 坑道の数値上の長さは無限に伸びるが、**ワールド上に実際に置くのは X = 0〜128 の範囲だけ**（5-3）
  - 何階層になっても、1 人あたりの広さは 16 × 約 136 ブロックで一定
  - Z 方向だけで約 370 万区画あるので、人数の上限は実質気にしなくてよい

### 5-3. 掘進とループ表示

- 累計採掘量が増えて表示する距離が 1m 進むたびに、切羽の断面を空気にして、4m ごとに坑木（柵＋板材）を立てる
- **ワールド上の坑道は、切羽の手前 64m 分だけを見せる**
  - 進み具合が 64m 未満のとき：坑道は X = 0 から進み具合の位置まで。切羽の位置は X ＝ 進み具合 ＋ 1
  - 64m 以上のとき：切羽は X = 64〜128 の間を進む
  - 切羽が X = 128 に達したら、坑道を「切羽が X = 64 にある状態」に作り直し、坑道内のプレイヤーを 64 ブロック手前へ同じ向きのままテレポートさせる
  - 坑木の間隔（4m）と地層は 64m 周期で同じ見た目なので、移動したことにほぼ気づかない
- 坑道が何 km になっても、坑底へ戻るときは**人車**（坑道を走る人を運ぶ車）に乗る扱いにする
  - 坑底の乗り場はいつも X = -8〜0 にある
  - アクションバーの距離は数値上の値（例：`1,234/4,960m`）を出す
- 1 秒に何 m も進む場合は、1 秒ごとにまとめて作り直す
- ブロックの置き換えは、**本人が自分の坑道にいるときだけ**行う
- 坑外やオフラインのときは、進み具合の数値だけ増やす

### 5-4. 入坑時の作り直し

- 入坑するたびに、区画を**最新の階層・今の進み具合**の状態に作り直す
  1. その階層の地層で区画を埋め直す
  2. 5-3 のルールで、見せる範囲の坑道を掘る
- 作り直す範囲は最大 128m なので、すぐ終わる
- 見た目の状態は保存しなくてよく、保存するのは数値だけ

### 5-5. 次の階層へ

数値上の階層は自動で進め、見た目の階層はケージに乗ったときに追いつく。

- **坑道の長さは階層ごとに 16m ずつ、上限なしで伸びる**（4-3 の L）
  - 第 1 坑道 64m → 第 2 坑道 80m → … → 第 100 坑道 1,648m → 第 4898 坑道 78,416m
  - ワールド上に置くのは 128m 分だけなので（5-3）、長くなっても問題ない
- 累計採掘量が次の階層の境目を超えたら、**数値上は自動で**次の階層へ進む（超えた分は次の階層の進み具合になる）
  - 毎秒の石炭は止まらないので、放置していても損をしない
  - 降りなかった階層の到達ボーナスは、あとで降りたときにまとめてもらえる（4-4）
- 坑内にいるプレイヤーへの誘導
  - ボスバー：「第 ◯ 坑道まで掘り進んでいます。ケージで降りよう」
  - 掘り切った切羽に看板を出す
  - 坑底へ向かうパーティクルの道しるべを出す
  - 掘り切った坑道の先には切羽がないので、手掘りもできない（ケージで降りれば再開できる）
- 坑底のケージを右クリックすると、降りる演出をして最新の階層へ移動する
  1. 暗転
  2. 巻揚機の音
  3. タイトル「第 ◯ 坑道 深さ ◯◯m」
  4. 区画を作り直して、坑底へテレポート
  - 何階層ぶん遅れていても一気に降りる
- 1 階層 ＝ 深さ 100m として表示する
- 階層ごとの地層

| 階層 | 地層 |
|---|---|
| 1〜3 | 石・砂岩 |
| 4〜6 | 凝灰岩が混ざる |
| 7〜 | 深層岩・深層石炭鉱石 |

## 6. 道具と改良

### 6-1. 道具（何個でも買える。クッキークリッカーの建物）

| ID | 道具 | アイコン | 初期価格 | 毎秒の石炭 |
|---|---|---|---|---|
| `lamp` | 安全灯 | ランタン | 150 | 1 |
| `minecart` | 炭車 | トロッコ | 1,000 | 10 |
| `blasting` | 発破 | TNT | 11,000 | 80 |
| `coal_pick` | コールピック | 鉄のツルハシ | 120,000 | 470 |
| `conveyor` | ベルトコンベア | パワードレール | 130 万 | 2,600 |
| `drum_cutter` | ドラムカッター | 砥石 | 1,400 万 | 14,000 |
| `shield` | 自走枠 | 鉄格子 | 2 億 | 78,000 |
| `headframe` | 立坑櫓 | 避雷針 | 33 億 | 44 万 |

- 価格は、買うたびに ×1.15
- 手掘りで 15 回叩く（150 個）と安全灯が買え、自動で石炭が増え始める

### 6-2. 改良（1 回だけ買える。クッキークリッカーのアップグレード）

| 種類 | 効果 | 出現条件 | 価格 |
|---|---|---|---|
| 道具の改良（道具ごとに 7 段階） | その道具の効果 2 倍 | その道具を 1・5・25・50・100・150・200 個持つ | 道具の初期価格 × 10・50・500・5 万・500 万・5 億・500 億 |
| ツルハシの改良（3 段階） | 手掘り 2 倍 | 手掘り 100・1,000・1 万回 | 1,000・10 万・1,000 万 |
| 熟練の改良（5 段階） | 手掘りに毎秒の石炭の 1% を上乗せ | 累計採掘量 5 万・500 万・5 億・500 億・5 兆 | 5 万・500 万・5 億・500 億・5 兆 |
| 全体の改良 | すべての石炭 ×1.1 など | 累計採掘量（追加していく） | 未定 |

- 改良の名前と解説は、実際の炭鉱技術の進歩（安全灯の改良、炭車の大型化、発破の技術、機械化など）から付ける。名前・解説・史実の確認は歴史班と相談する

### 6-3. ショップ（`/coal shop`）

- チェスト型の画面。上段に「石炭の残高」「毎秒の石炭」「手掘り 1 回の石炭」を並べる
- 道具：説明文に価格（足りなければ赤字）・所持数・「1 つ買うと毎秒 +◯個」・この道具の合計（毎秒 ◯個、全体の ◯%）・短い解説
- 改良：買えるようになった改良だけを並べる。説明文に効果・価格・短い解説
- クリックで 1 つ購入、シフトクリックで買えるだけ（最大 10）。画面は開いたまま更新
- はじめて買った道具・改良は、チャットに詳しい解説を出す

### 6-4. 道具の解説文（仮）

- **安全灯**：暗い坑内で欠かせない明かり。炭鉱には燃えやすいガスがたまることがあり、火が外に出ない仕組みの灯りが使われました。
- **炭車**：掘った石炭を積んでレールの上を運ぶ車。坑道には何両もの炭車がつながって走りました。
- **発破**：岩盤に穴をあけて火薬を詰め、一度にまとめて砕く方法。硬い岩の中に坑道を掘り進めるのに欠かせませんでした。
- **コールピック**：圧縮空気の力で先端を何度も打ち付ける採炭機。坑夫 1 人あたりの採炭量を大きく増やしました。
- **ベルトコンベア**：掘った石炭を切羽から休みなく運び出す設備。運び出しの待ち時間が減り、掘る時間が増えました。
- **ドラムカッター**：長い切羽に沿って走りながら、回転するドラムで炭壁を削り、そのままコンベアに積み込む採炭機。
- **自走枠**：油圧で天井を支えながら、自分で前へ進む鋼鉄の枠。長い切羽でも安全に掘れるようになりました。
- **立坑櫓**：地下深くまで続く立坑の上に建つ櫓。巻揚機の滑車でケージを上げ下げし、人や石炭を運びました。美唄には今も赤い立坑櫓が残っています。

## 7. 表示・操作

- **アクションバー**：`石炭 1,234個 ｜ 毎秒 12.3個 ｜ 第2坑道 深さ200m 37/80m`（ケージ待ちのときは「ケージで降りよう」を添える）
- **サイドバー**：サーバー全体の出炭量
- 坑内ではアドベンチャーモードにする。ブロックは壊せず、叩いた判定だけ取る
- 自分の坑道の切羽（3×3）を叩いたときだけ、手掘りとして数える

## 8. データ

`plugins/CoalClicker/players/<UUID>.yml`

```yaml
coal: "1.2345e3"       # 今持っている石炭（BigNum を文字列で保存）
totalMined: "5.6789e4" # 累計採掘量
clicks: 320           # 手掘りの回数（ツルハシの改良の出現条件）
tools: { lamp: 10, minecart: 4 }
upgrades: [lamp_1, lamp_2, pickaxe_1]   # 買った改良
explained: [lamp, lamp_1]   # 解説を表示済みの道具・改良
mine:
  section: 2           # 区画番号
  maxReachedLevel: 1   # 到達ボーナスを受け取った一番深い階層
  # 数値上の階層と進み具合は累計採掘量から計算するので保存しない
lastSeen: 1764000000   # 最後にいた時刻（オフライン中の分の計算用）
```

`plugins/CoalClicker/mine.yml`

```yaml
nextSection: 5         # 次に割り当てる区画番号
serverTotalMined: "0"  # サーバー全体の出炭量
```

- 保存するタイミング：ログアウト時、60 秒ごと、サーバー停止時
- 今どの階層が描かれているか、ヒビの段階などは保存しない（メモリ上だけで持つ）

### フェーズ 5 のメモ

- 買った道具を坑道に置く（安全灯→ランタン、炭車→レールとトロッコ）
- 発破：爆発音、煙のパーティクル、画面の揺れ
- コールピック：連続した打撃音
- コンベアやドラムカッター：機械の動作音、坑道に機械の見た目（ディスプレイエンティティ）を置く
- 巻揚機：ケージで降りるときの巻き上げ音

## 10. アイデアメモ

- **良質な炭層**（クッキークリッカーのゴールデンクッキーに当たるもの）：ときどき坑道の壁が光り、叩くと一定時間、毎秒の石炭 ×7 などのボーナス
- 実績

- サーバー全体の出炭量を、実際の美唄の炭鉱の出炭量と比べて表示する（例：「みんなで三菱美唄炭鉱の ◯ 年分を掘りました」）。実際の数値は要確認
- 「新しい切羽を開く」などで道具を増やす（ベルトコンベア、ドラムカッター、自走枠、立坑櫓など）
