# 石炭クリッカー 企画書

美唄ハッカソン（テーマ「美唄を倍にする」）向けの Minecraft プラグイン。
かつて炭鉱で栄えた美唄の歴史を、放置ゲームを通して知ってもらう。

## 1. コンセプト

**自分の坑道を掘り進め、どんどん深い層へ降りていく放置ゲーム。**

- 坑道を掘り進めると石炭が集まる。道具を買うと自動で掘り進めてくれる
- 1 本の坑道を掘り切ったら、立坑のケージで一段深い階層へ降りる。深い層ほど石炭が多く採れる
- 道具の解説を通して、炭鉱の歴史や仕組みを知ってもらう

## 3. 遊びの流れ

1. `/coal mine` で、自分の坑道の先端（切羽）へ入坑する
2. 切羽を叩くとヒビが入り、**10 回目で崩れて坑道が 1m 進み、石炭がもらえる**
3. `/coal shop` で道具を買うと、自動で掘り進めて石炭が増えていく
4. 坑道をその階層の長さ（最初は 64m。深くなるほど少しずつ長くなる）まで掘り切ると、数値上は自動で次の階層へ進む。坑内にいる場合はケージで降りるよう誘導する
5. ケージで新しい深さに到達すると、**到達ボーナス**がもらえる
6. 坑外にいる間やログアウト中も、自動の掘進は進む（ログアウト中の分はフェーズ 3 で対応）

## 4. 数値の仕組み

単位は「個」。以下の数値はすべて初期値で、あとで調整する。

### 4-1. 掘進力 D と採炭力 E

石炭は**坑道を掘り進めた分だけ**採れる。ステータスは 2 つで、道具ごとにどちらかが上がる。

| ステータス | 上がる道具 | 効果 |
|---|---|---|
| **掘進力 D** | 発破・削岩機 | 坑道を自動で掘り進める速さが上がる |
| **採炭力 E** | 安全灯・炭車・コールピック | 1m 掘ったときに採れる石炭が増える（初期値 100） |

| 数値 | 計算式 | 意味 |
|---|---|---|
| 掘進速度（m/秒） | 0.1 × √D | 掘進の道具を買うほど速くなる。D = 0 なら自動では進まない |
| 1m あたりの石炭 | E × 深さ倍率 | 採炭の道具と深さで増える |
| 毎秒の石炭 | 掘進速度 × 1m あたりの石炭 | 掘り進めた分だけ石炭が入る |
| 深さ倍率 | 1.1 ^ 階層番号（0 始まり） | 深い層ほど石炭が多い |
| 坑道の長さ L | 64 + 16 × 階層番号（m） | 1 階層ごとに 16m ずつ伸びる |
| 1 階層にかかる時間 | max(L ÷ 掘進速度, 10 秒) | 深い層ほど坑道が長く、時間がかかる。最短 10 秒（安全装置） |

- 掘進速度は坑道の長さに関係しない。坑道の伸び方が掘進速度の伸び方より速いので、**深くなるほど 1 階層にかかる時間が伸びていく**
- **どちらに投資するかが悩みどころ**になる
  - 採炭だけ：1m あたりの量は増えるが、自動では掘り進まない
  - 掘進だけ：速く掘れるが、1m あたりの量が少ない
  - 両方をバランスよく買うのが一番伸びる

### 4-2. 手掘り（クリック）

- 切羽を 1 回叩くと、ヒビが 1 段階進む（Minecraft のヒビの 10 段階をそのまま使い、ゲージは出さない）
- 10 回目で切羽が崩れ、**1m 進む**
- 崩したときにもらえる石炭 ＝ (採炭力 E ＋ 100 × ツルハシの所持数) × 深さ倍率
- 叩いただけでは石炭は出ない。崩したときだけ、効果音と `+◯個` を表示する

### 4-3. 到達ボーナス

- **はじめて到達した階層**に、ケージか入坑で実際に着いたときにもらえる
- 1 階層あたりのボーナス ＝ 掘進速度 × 採炭力 E × その階層の深さ倍率 × 60 秒分（その階層での毎秒の石炭の 1 分ぶん）
  - 最低保証は、その階層で 1m 掘った分（E × 深さ倍率）
  - 例：第 2 坑道（深さ倍率 1.1）に 掘進速度 0.2m/秒・E = 200 で着くと、約 2,640 個
- 自動の掘進で階層が進んでいて、**降りなかった階層がある場合は、その分もまとめてもらえる**
  - 例：第 2 坑道から一気に第 5 坑道へ降りたら、第 3・4・5 坑道のボーナスを合計してもらえる
  - 深さ倍率は等比数列なので、合計は等比数列の和の公式で一度に計算する。何百万階層ぶんでも一瞬で計算できる

### 4-4. どんなに大きな数でも扱えるようにする

Java の `double` は約 10^308 が上限で、深い階層では石炭の数がこれを超えてしまう。そこで、数値は次のように持つ。

| 値 | 持ち方 | 扱える範囲 |
|---|---|---|
| 石炭・採炭力・掘進力・価格・深さ倍率など | 自作の `BigNum`（仮数 `double` 1〜10 未満 ＋ 指数 `long`） | 10^(9×10^18) まで。事実上無限 |
| 階層番号 | `long` | 約 900 京階層まで |
| 今の階層の進み具合 | **割合**（0〜1 の `double`） | 坑道の長さに関係なく精度が落ちない。m 表示は 割合 × L で出す |

- 深さ倍率 1.1^n は、指数 ＝ n × log10(1.1) として直接求める（掛け算を n 回しない）
- 表示は日本の単位で区切る：万・億・兆・京・垓・秭・穣・溝・澗・正・載・極・恒河沙・阿僧祇・那由他・不可思議・無量大数
- 無量大数（10^68）を超えたら `1.23×10^1234個` のように表示する
- 保存は文字列にする（例：`"1.234e5678"`）

## 5. 坑道システム

### 5-1. 専用ワールド `bibai_mine`

- プラグインが起動時に自動で作る
- 地形は全部岩。空も洞窟もない
- 坑道の高さに地層をつくる

```
Y43-44  砂岩        ← 天井
Y41-42  炭層（石炭鉱石）
Y40     石          ← 床
それ以外 石
```

### 5-2. 区画（1 人 1 本）

- はじめて入坑した順に**区画番号**を割り当てる（0, 1, 2, …）
- 区画 n の坑道は、**Z = n × 16** の位置を **X = 0 から +X 方向**へ伸びる
- 坑道の断面は 幅 3 × 高さ 3（Y41〜43）
- X = -8〜0 は坑底（ケージと人車の乗り場）
- 区画が保持するのは**今の階層の坑道 1 本だけ**
- 坑道の数値上の長さは無限に伸びるが、**ワールド上に実際に置くのは X = 0〜128 の範囲だけ**（5-3）
  - 何階層になっても、1 人あたりの広さは 16 × 約 136 ブロックで一定
  - Z 方向だけで約 370 万区画あるので、人数の上限は実質気にしなくてよい

### 5-3. 掘進とループ表示

- 進み具合を、手掘りと自動の掘進の両方で増やす
- 1m 進むたびに、切羽の断面を空気にして、4m ごとに坑木（柵＋板材）を立てる
- **ワールド上の坑道は、切羽の手前 64m 分だけを見せる**
  - 進み具合が 64m 未満のとき：坑道は X = 0 から進み具合の位置まで。切羽の位置は X ＝ 進み具合 ＋ 1
  - 64m 以上のとき：切羽は X = 64〜128 の間を進む
  - 切羽が X = 128 に達したら、坑道を「切羽が X = 64 にある状態」に作り直し、坑道内のプレイヤーを 64 ブロック手前へ同じ向きのままテレポートさせる
  - 坑木の間隔（4m）と地層は 64m 周期で同じ見た目なので、移動したことにほぼ気づかない
- 坑道が何 km になっても、坑底へ戻るときは**人車**（坑道を走る人を運ぶ車）に乗る扱いにする
  - 坑底の乗り場はいつも X = -8〜0 にある
  - アクションバーの距離は数値上の値（例：`1,234/4,960m`）を出す
- 掘進速度が速くて 1 秒に何 m も進む場合は、1 秒ごとにまとめて作り直す
- ブロックの置き換えは、**本人が自分の坑道にいるときだけ**行う
- 坑外やオフラインのときは、進み具合の数値だけ増やす

### 5-4. 入坑時の作り直し

- 入坑するたびに、区画を**最新の階層・今の進み具合**の状態に作り直す
  1. その階層の地層で区画を埋め直す
  2. 5-3 のルールで、見せる範囲の坑道を掘る
- 作り直す範囲は最大 128m なので、すぐ終わる
- 見た目の状態は保存しなくてよく、保存するのは数値だけ

### 5-5. 次の階層へ

数値上の階層は自動で進め、見た目の階層はケージに乗ったときに追いつく。

- **坑道の長さは階層ごとに 16m ずつ、上限なしで伸びる**（4-1 の L）
  - 第 1 坑道 64m → 第 2 坑道 80m → … → 第 100 坑道 1,648m → 第 4898 坑道 78,432m
  - ワールド上に置くのは 128m 分だけなので（5-3）、長くなっても問題ない
- 進み具合は **その階層の長さで止まり、それ以上は掘れない**（超えた分は捨てる）
- 長さに達したら、**数値上は自動で**階層番号を +1 し、次の階層は 0m から掘り始める
  - 自動の掘進も石炭の獲得も止まらないので、放置していても損をしない
  - 降りなかった階層の到達ボーナスは、あとで降りたときにまとめてもらえる（4-3）
- 坑内にいるプレイヤーへの誘導
  - ボスバー：「第 ◯ 坑道まで掘り進んでいます。ケージで降りよう」
  - 掘り切った切羽に看板を出す
  - 坑底へ向かうパーティクルの道しるべを出す
  - 掘り切った坑道の先には切羽がないので、手掘りもできない
- 坑底のケージを右クリックすると、降りる演出をして最新の階層へ移動する
  1. 暗転
  2. 巻揚機の音
  3. タイトル「第 ◯ 坑道 深さ ◯◯m」
  4. 区画を作り直して、坑底へテレポート
  - 何階層ぶん遅れていても一気に降りる
- 1 階層 ＝ 深さ 100m として表示する
- 階層ごとの地層

| 階層 | 地層 |
|---|---|
| 1〜3 | 石・砂岩 |
| 4〜6 | 凝灰岩が混ざる |
| 7〜 | 深層岩・深層石炭鉱石 |

## 6. 道具（MVP は 6 種類）

| ID | 道具 | アイコン | 種類 | 初期価格 | 効果 |
|---|---|---|---|---|---|
| `pickaxe` | ツルハシ | 木のツルハシ | 手掘り | 500 | 1m 崩したときの石炭 +100 個 |
| `lamp` | 安全灯 | ランタン | 採炭 | 150 | 採炭力 +10（1m あたり +10 個） |
| `minecart` | 炭車 | トロッコ | 採炭 | 1,000 | 採炭力 +100 |
| `coal_pick` | コールピック | 鉄のツルハシ | 採炭 | 12,000 | 採炭力 +1,000 |
| `blasting` | 発破 | TNT | 掘進 | 200 | 掘進力 +1 |
| `drill` | 削岩機 | ピストン | 掘進 | 5,000 | 掘進力 +10 |

- 手掘りで 20 回叩く（2m・200 個）と発破が買え、自動で掘り始める
- 価格は、買うたびにツルハシは ×2.0、自動系は ×1.15 になる
- ショップ（`/coal shop`）はチェスト型の画面
  - 掘進力と採炭力のアイコンを置き、説明文に今の値とステータスの説明を出す
    - 掘進力：坑道を自動で掘り進める速さ。上げると自動で石炭が集まるようになる
    - 採炭力：1m 掘ったときに採れる石炭の量。手掘りにも自動にも効く
  - 説明文に、価格・所持数・効果・短い解説を表示する
  - 石炭が足りない場合は、価格を赤字で表示する
  - クリックで 1 つ購入し、成功音・失敗音を鳴らす
  - 画面は開いたまま内容を更新する
- はじめて買った道具は、チャットにも詳しい解説を出す

### 解説文（仮）

- **ツルハシ**：炭鉱の始まりは手掘りでした。炭壁の下に切り込みを入れ、楔で石炭を割り落とします。
- **安全灯**：暗い坑内で欠かせない明かり。炭鉱には燃えやすいガスがたまることがあり、火が外に出ない仕組みの灯りが使われました。
- **炭車**：掘った石炭を積んでレールの上を運ぶ車。坑道には何両もの炭車がつながって走りました。
- **発破**：岩盤に穴をあけて火薬を詰め、一度にまとめて砕く方法。硬い岩の中に坑道を掘り進めるのに欠かせませんでした。
- **コールピック**：圧縮空気の力で先端を何度も打ち付ける採炭機。坑夫 1 人あたりの採炭量を大きく増やしました。
- **削岩機**：圧縮空気の力で岩に発破用の穴をあける機械。手作業より何倍も速く穴をあけられ、坑道を掘る速さが大きく上がりました。

## 7. 表示・操作

- **アクションバー**：`石炭 1,234個 ｜ 毎秒 12.3個 ｜ 第2坑道 深さ200m 37/80m`
- **サイドバー**：サーバー全体の出炭量
- 坑内ではアドベンチャーモードにする。ブロックは壊せず、叩いた判定だけ取る
- 自分の坑道の切羽（3×3）を叩いたときだけ、手掘りとして数える

### コマンド

| コマンド | 権限 | 内容 |
|---|---|---|
| `/coal` | 全員 | 自分の記録を表示 |
| `/coal mine` | 全員 | 自分の坑道へ入坑する |
| `/coal surface` | 全員 | 地上へ戻る |
| `/coal shop` | 全員 | ショップを開く |
| `/coal top [mined\|depth\|rate]` | 全員 | ランキング（累計採掘量・到達深さ・毎秒採掘量） |
| `/coal admin give <player> <量>` | OP | 石炭を付与（デモ用） |
| `/coal admin reset <player>` | OP | データを初期化 |

## 8. データ

`plugins/CoalClicker/players/<UUID>.yml`

```yaml
coal: "1.2345e3"       # 今持っている石炭（BigNum を文字列で保存）
totalMined: "5.6789e4" # 累計採掘量
tools: { pickaxe: 3, lamp: 10, minecart: 4 }
explained: [pickaxe, lamp]   # 解説を表示済みの道具
mine:
  section: 2           # 区画番号
  level: 1             # 数値上の階層（0 始まり）
  progress: 0.584      # 今の階層での進み具合（割合 0〜1）
  maxReachedLevel: 1   # 到達ボーナスを受け取った一番深い階層
lastSeen: 1764000000   # 最後にいた時刻（オフライン中の分の計算用）
```

`plugins/CoalClicker/mine.yml`

```yaml
nextSection: 5         # 次に割り当てる区画番号
serverTotalMined: "0"  # サーバー全体の出炭量
```

- 保存するタイミング：ログアウト時、60 秒ごと、サーバー停止時
- 今どの階層が描かれているか、ヒビの段階などは保存しない（メモリ上だけで持つ）
